Web Security

Web security protects applications from attacks. Core concerns include input validation, authentication, authorisation, encryption, and dependency management. The OWASP Top 10 is the industry reference for critical application security risks. Common threats: SQL Injection, XSS, CSRF, and insecure direct object references. Secure headers (CSP, HSTS, X-Frame-Options) form a critical first line of defence.

Web Hosting

Hosting choices range from shared hosting to VPS, dedicated servers, and cloud platforms. Key considerations: uptime SLAs, server location / latency, SSL/TLS support, and backup and recovery provisions. PaaS platforms like Vercel and Netlify simplify modern deployment significantly.

Scalability & Availability

Scalability: a system's ability to handle increased load — vertical (more power to one server) or horizontal (more servers). Availability: how reliably a system is accessible, expressed as a percentage (99.9% = ~8.7h downtime/year). Strategies: load balancing, CDN caching, database replication, health checks, auto-scaling groups, and redundant architecture to eliminate single points of failure.

⚖️

Load Balancing

Distributing traffic across multiple servers to prevent overload and improve response times. Essential for high-traffic sites.

User Access & Resources

User Access Management controls who can access what, following the principle of least privilege. This covers authentication (verify identity), authorisation (define permissions), and audit logging. Resource allocation — how CPU, RAM, bandwidth, and storage are provisioned — is handled dynamically in cloud environments. Rate limiting and quotas prevent abuse and ensure fair distribution.

🔑

OAuth 2.0 / OIDC

Industry-standard delegated authorisation and identity federation. Powers "Login with Google" and SSO flows.

AuthIdentity
🧱

Role-Based Access Control

Permissions assigned to roles, not individuals. Simplifies management at scale and enforces least-privilege.

AccessEnterprise
